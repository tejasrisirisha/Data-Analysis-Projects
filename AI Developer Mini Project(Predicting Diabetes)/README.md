# Diabetes Prediction using Machine Learning

## Overview

This project predicts whether a patient is **Diabetic** or **Not Diabetic** using the **Pima Indians Diabetes Dataset**. It follows a complete Machine Learning workflow from data loading to prediction.

## Features

* Data Loading
* Data Cleaning
* Exploratory Data Analysis (EDA)
* Train-Test Split
* Model Training
* Model Evaluation
* User Prediction
* Model Saving using Joblib
* Reusable Python Functions

## Reusable Functions

* `load_data()`
* `clean_data()`
* `split_data()`
* `train_model()`
* `predict()`
* `save_model()`

## Models Used

* Logistic Regression
* KNN
* Decision Tree

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1 Score
* Confusion Matrix

## Technologies

Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Joblib, Google Colab

## Output

The trained model predicts whether a patient is:

* **Diabetic**
* **Not Diabetic**
