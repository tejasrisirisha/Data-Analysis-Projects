# Customer Purchase Prediction

## Objective
Build a machine learning model to predict whether a customer will purchase a product based on customer data.

## Dataset
- Mall Customer / Customer Purchasing Dataset (CSV)

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

## Workflow
- Data Loading
- Data Cleaning
- Encoding
- Correlation Analysis
- Data Visualization
- Feature Scaling
- Model Training
- Model Evaluation
- Model Saving
- Customer Purchase Prediction

## Machine Learning Models
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Output
The best-performing model is saved using Joblib and used to predict purchase status for new customers.
