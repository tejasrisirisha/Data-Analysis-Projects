# Customer Purchase Prediction

## Objective

Build a Machine Learning model to predict customer purchase behavior.

## Tools

Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Joblib

## Workflow

* Data preprocessing
* Data visualization
* Feature encoding & scaling
* Model training (Logistic Regression, KNN, Decision Tree)
* Model evaluation
* Best model prediction

## Result

Compared all models using Accuracy, Precision, Recall, F1-score, and Confusion Matrix, then saved the best-performing model.
