#  Diamond Price Analysis

##  Objective

Analyze the factors that influence diamond prices using Exploratory Data Analysis (EDA). The project focuses on data cleaning, statistical analysis, outlier detection, visualization, and extracting meaningful business insights.

##  Dataset

* Diamonds Dataset (CSV)

##  Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

##  Project Tasks

* Load and explore the dataset
* Clean the data
* Handle missing values and duplicates
* Detect and treat outliers
* Analyze numerical and categorical features
* Compute statistical measures
* Perform correlation analysis
* Create visualizations
* Generate business insights

##  Visualizations

* Histogram
* Scatter Plot
* Bar Chart
* Box Plot
* Heatmap
* Pair Plot

## 🎯 Outcome

Identified the key factors affecting diamond prices and extracted insights that can support pricing decisions and market analysis.
