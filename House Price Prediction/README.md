House Price Prediction

Objective:
Build a Machine Learning model to predict house prices using Linear Regression techniques.

Dataset:
Housing Prices Dataset

Tasks Performed:
Loaded and explored the dataset.
Calculated statistical measures (Mean, Median, Mode, Variance, Standard Deviation).
Identified feature skewness.
Detected outliers using boxplots.
Analyzed feature correlations using a heatmap.
Selected the top correlated features.
Built Simple Linear Regression and Multiple Linear Regression models.
Compared model performance using RMSE and R² Score.
Predicted prices for 10 unseen houses.
Saved the best-performing trained model.

Tools & Libraries:
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Joblib

Outcome:
Successfully developed and evaluated Linear Regression models for house price prediction and saved the best model for future use.
