# Student Performance Analysis

## Objective

Analyze student exam performance and identify factors affecting scores using Exploratory Data Analysis (EDA).

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib

## Tasks Performed

* Loaded the dataset
* Performed EDA
* Handled missing values and duplicates
* Calculated statistical measures
* Detected and treated outliers
* Performed correlation analysis
* Created bar chart, line chart, histogram, and scatter plot
* Saved the cleaned dataset

## Output

A cleaned dataset and visualizations that provide insights into student performance.
